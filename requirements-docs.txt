# MkDocs and theme
#
# mkdocs is capped below 2.0 on purpose: MkDocs 2.0 is a from-scratch rewrite
# by the original maintainer that removes the plugin system entirely,
# rewrites the theme API, has no upgrade path, and (as of this writing) ships
# with no open-source license -- see
# https://squidfunk.github.io/mkdocs-material/blog/2026/02/18/mkdocs-2.0/.
# Every plugin below, plus docs/_hooks/*.py's use of `hooks:`, depends on the
# plugin system 2.0 removes, so an uncapped `pip install` picking up a future
# `mkdocs==2.0.0` from PyPI would break this build outright. If that day
# comes, the fix is almost certainly switching to properdocs (a maintained,
# drop-in-compatible fork of classic MkDocs 1.x: `pip install properdocs`,
# same mkdocs.yml, same plugins, just swap the `mkdocs` command for
# `properdocs`) rather than chasing 2.0 compatibility.
mkdocs>=1.5.0,<2.0.0
mkdocs-material>=9.0.0,<10.0.0

# MkDocs plugins
mkdocs-mermaid2-plugin>=0.6.0
mkdocs-git-revision-date-localized-plugin>=1.2.0
mkdocs-print-site-plugin>=2.3.0

# Additional dependencies for markdown extensions
pymdown-extensions>=10.0

# Reference-page generation: docs/_hooks/*.py shells out to `python -m typer`
# to render docs/reference/cli.md, which needs abtv2-tools' `abt` package
# importable -- also install abtv2-tools/requirements-dev.txt (or activate
# its env.yaml conda env) alongside this file. The other hooks only read
# rbt-schema/*.json, */*.yml, and tile-metadata/metadata.py directly with
# the standard library plus PyYAML (already required by requirements-dev.txt).
#
# Typer and rich are pinned to exact versions because docs/reference/cli.md is
# a committed page and both shape its text: Typer decides how each option's
# type reads, and renders the help through rich. Typer 0.29 showed a
# repeatable path option as <list[Path]> where 0.27 showed <path>, and the
# Docs workflow fails a pull request whose committed page differs from the one
# it builds, so an unpinned release fails every such pull request until
# someone regenerates the page.
#
# The pins cover the docs build only. abtv2-tools/requirements-dev.txt and
# env.yaml still accept any Typer from 0.12; installing this file into the
# same environment sets it to the version below.
#
# To move to a newer release, change the pin, run `mkdocs build --strict` on
# Python 3.13, and commit what changes under docs/ in the same pull request.
typer==0.29.2
rich==15.0.0
