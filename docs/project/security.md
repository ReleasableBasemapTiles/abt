# Security

!!! warning "No formal security policy yet"
    This repository does not currently include a `SECURITY.md` or any other formal security policy. The guidance below is generic and non-binding, not a documented process.

This repo (`ReleasableBasemapTiles/abt` on GitHub) is currently private. If you believe you've found a security issue:

- Report it privately to the maintainers rather than in a public issue — for example, via a private GitHub security advisory on the repo (if enabled), or directly to a maintainer.
- Avoid filing public issues or PRs that describe the vulnerability in detail before a maintainer has had a chance to respond.

There is no documented disclosure policy, response-time commitment, or dedicated security contact for this project at this time — treat the above as a starting point until the maintainers publish something more formal.
